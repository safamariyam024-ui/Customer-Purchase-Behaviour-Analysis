Analysis of retail sales, customer purchase patterns, sales trends, and RFM-based customer segmentation using Python.
# Customer Purchase Behaviour Analysis

## Project Overview
This project analyzes retail sales data to understand customer purchasing
behaviour, product performance, sales trends, and customer segments.

## Objectives
- Analyze overall retail sales.
- Identify top-selling products.
- Compare sales across countries.
- Study monthly sales trends.
- Segment customers using RFM analysis.

## Dataset
The project uses the Online Retail dataset and a cleaned, preprocessed version.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn (if used in the notebook)
- Jupyter Notebook / Google Colab
- Excel

## Visualizations
- Sales by Country
- Monthly Sales Trend
- Top 10 Products
- Customer Segmentation

## Key Findings
- Total recorded sales: 8,887,208.89
- Unique customers: 4,338
- Average invoice value: 479.56
- The United Kingdom has the highest recorded sales.

## Customer Segmentation
RFM analysis was used to group customers based on recency, frequency,
and monetary value.

## Project Files
- Python notebook
- Original and cleaned datasets
- Customer segmentation results
- Visualization images
- Final project report PDF

## How to Run
1. Download the notebook and dataset.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Install any required libraries.
4. Run the notebook cells in order.
